# Brewing-Sim

**Brewing-Sim** is an educational application developed using C++ and the Qt framework. It offers users an immersive experience into the rich history, cultural significance, and biochemical processes of alcoholic beverage production across various regions of the world. The application serves as an interactive tool for learning about traditional brewing and distillation methods, emphasizing both cultural context and scientific principles.

## Features

- **Global Cultural Exploration**: Delve into the traditions and histories of alcoholic beverages from diverse regions, including:
  - **Japan**: Discover the art and cultural importance of Sake brewing.
  - **Brazil**: Learn about traditional fermentation techniques unique to Brazilian culture.
  - **Caribbean**: Explore the methods and cultural narratives surrounding rum production.
  - **And More!**

- **Biochemical Process Education**: Understand the scientific processes involved in brewing and distillation, such as fermentation, distillation, and aging.

- **Interactive Learning Modules**: Engage with multimedia content, including animations and interactive diagrams, to visualize complex processes and cultural practices.

- **User-Friendly Interface**: Navigate through the application with an intuitive UI designed for educational purposes, suitable for both classroom settings and individual exploration.

## Installation

### Prerequisites

- Qt Framework (version 5.x or higher)
- C++ Compiler (supporting C++11 standard or higher)

### Steps

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Celestron1123/Brewing-Sim.git
   ```

2. **Navigate to the Project Directory**:
   ```bash
   cd Brewing-Sim
   ```

3. **Open the Project in Qt Creator**:
   - Launch Qt Creator.
   - Open the `BrewingSimulator.pro` file located in the project directory.

4. **Build and Run**:
   - Configure the project using the appropriate kit for your system.
   - Build the project (may take a few minutes).
   - Run the application within Qt Creator.

## Usage

Upon launching the application, users can select a region to explore its unique alcoholic beverage traditions. Each module provides:

- Historical background and cultural significance.
- Step-by-step breakdown of brewing/distillation processes.
- Interactive elements to enhance understanding.

The Japan module, for instance, offers an in-depth look at Sake production, from mixing to fermentation, highlighting its role in Japanese ceremonies and daily life.

## Project Structure

The project is organized into modules corresponding to different regions. Each module comprises:

- `.cpp` and `.h` files: Contain the logic and data structures.
- `.ui` files: Define the user interface layouts.
- Resource files: Include images, animations, and other multimedia assets.

For example, the `japan.cpp`, `japan.h`, and `japan.ui` files collectively manage the Japan module's functionality and presentation.
